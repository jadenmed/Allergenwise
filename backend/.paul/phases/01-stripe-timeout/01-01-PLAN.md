<objective>
## Goal
Cap the Stripe SDK network timeout from its 80,000ms default to `timeout: 10000` and add `maxNetworkRetries: 2` in the `new Stripe(...)` constructor options in `lib/stripe.ts`. Nothing else.

## Purpose
Audit Part A #3a. Every user-facing payment path (signup `customers.create`/`paymentIntents.create`, payment-intent route, charge-cert-fees) inherits the SDK's 80s default timeout. A hung Stripe socket can block a user request for up to 80 seconds. Capping to 10s fast-fails; `maxNetworkRetries: 2` (up from SDK default 1) recovers transient network blips. Behavior-preserving — callers, return shapes, and idempotency keys are untouched; only network timeout/retry config changes.

## Output
- Modified `lib/stripe.ts`
- `.paul/phases/01-stripe-timeout/01-01-SUMMARY.md`
