<task type="auto">
  <name>Task 1: Create lib/auth/require-auth.ts + lib/auth/require-role.ts</name>
  <files>lib/auth/require-auth.ts, lib/auth/require-role.ts</files>
  <action>
    require-auth.ts:
    - `jsonError(status: number, message: string): NextResponse` → `NextResponse.json({ error: message }, { status })`
    - `unauthorized(message = 'Unauthorized')` → jsonError(401, message)
    - `forbidden(message = 'Forbidden')` → jsonError(403, message)
    - `requireAuth(opts?: { message?: string }): Promise<{ user: User } | NextResponse>` — createServerSupabase → auth.getUser(); no user (or error) → unauthorized(opts.message)

    require-role.ts:
    - `requireRole(opts)` with options:
      - `roles: string[]` (allowed role values — exact strings, e.g. ['reviewer'], ['manager'], ['learner','admin'])
      - `profileClient: 'session' | 'service'` (which client reads profiles — MUST match original per route)
      - `columns: string` (exact select string per route, e.g. 'id, role, restaurant_id, full_name')
      - `unauthorizedMessage?: string` (default 'Unauthorized')
      - `forbiddenMessage?: string` (default 'Forbidden')
      - `onMissingProfile?: 'unauthorized' | { status: number; message: string }` (default 'unauthorized' — matches admin/reviewer cluster)
      - `requireRestaurant?: { status: number; message: string }` (post-role check that profile.restaurant_id is non-null)
    - Returns `{ user, profile } | NextResponse`. Profile typed loosely matching existing route-local casts.
    - getUser via createServerSupabase always (all 21 routes do this). Profile read via createServerSupabase (session) or createServiceDb (service) per opts.
  </action>
  <verify>pnpm tsc --noEmit passes with new files</verify>
