<objective>
## Goal
Convert sequential, provably-independent `await supabase...` reads into `Promise.all` batches across 6 files. Kill one redundant duplicate certificates query in dashboard-stats. Behavior-preserving: identical data returned, identical error precedence, dependent reads left sequential.

## Purpose
Audit B2. These handlers sit on hot paths (eligibility gates a Stripe charge; roster/dashboard are the manager landing; reviewer detail + auto-checks are never cached). Each currently pays N serial round-trips for reads that only depend on a shared id. Parallelizing removes 3–4 serial RTTs per request with no change to results.

## Output
- 6 modified files (reads parallelized)
- `.paul/phases/02-db-waterfalls/02-01-SUMMARY.md`
</objective>
