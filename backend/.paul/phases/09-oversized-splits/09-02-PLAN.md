## Goal
Extract `<PlanSelector>`, `<PaymentStep>`, `<AccountFields>` out of `app/(auth)/signup/SignupForm.tsx`'s single 455-line render function, zero behavior change to demo-mode gating, validation, or the Stripe confirm-payment flow.

Audit item B10 (Tier 3, pure clarity). One giant `onSubmit` + JSX return mixes restaurant fields, account fields, plan selection, and Stripe PaymentElement in one function — the highest-risk file in the app (real money path) to review as one block.

## Output
4 new co-located files (schema + 3 field-group components) + trimmed SignupForm.tsx. Demo-mode banner, submit-button gating, and `stripe.confirmPayment` call untouched.
</objective>
